Brandify AI – بسته آماده راه‌اندازی با هوش مصنوعی واقعی

این نسخه رابط کاربری را به یک تابع سمت سرور Netlify وصل می‌کند. تابع، اطلاعات فرم را به Gemini می‌فرستد و برنامه اختصاصی برند شخصی را برمی‌گرداند.

ساختار پوشه:
- public/: فایل‌های قابل مشاهده سایت
- netlify/functions/brand-plan.js: تابع امن سمت سرور
- netlify.toml: تنظیمات انتشار سایت و تابع

مهم:
۱) این بسته به‌تنهایی به Gemini وصل نیست؛ برای فعال شدن باید کلید API در تنظیمات محیطی Netlify ثبت شود.
۲) نام متغیر محیطی دقیقاً GEMINI_API_KEY است.
۳) کلید API را هرگز در index.html، فایل‌های public یا پیام عمومی قرار ندهید.
۴) برای اینکه تابع سمت سرور واقعاً منتشر شود، پروژه باید از روشی استفاده کند که Netlify Functions را پردازش کند؛ روش مطمئن، اتصال پروژه به Git و Deploy خودکار Netlify یا انتشار با Netlify CLI است. بارگذاری ساده فایل‌های استاتیک از Netlify Drop ممکن است فقط سایت را منتشر کند و تابع را فعال نکند.
۵) پس از ثبت متغیر محیطی، یک Deploy جدید لازم است.
۶) قبل از ارائه عمومی، محدودیت درخواست، سیاست حریم خصوصی و سهمیه/هزینه حساب Gemini را بررسی کنید.

مدل تنظیم‌شده: gemini-3.5-flash-lite. دسترسی و سهمیه مدل تابع شرایط حساب و منطقه سرویس است.
